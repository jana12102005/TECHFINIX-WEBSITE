# TECHFINIX '26 — National Level Biotechnology Symposium Website

![TECHFINIX '26 Banner](app/static/images/techfinix_bg.jpg)

## 🧬 Overview
**TECHFINIX '26** is the official web application for the National Level Biotechnology Symposium organized by the **Department of Biotechnology, Paavai Engineering College**.

The web platform features:
- 🎬 **Cinematic Biotechnology Intro & Background Video Engine**: Full HD video playback with audio synthesis.
- 🗺️ **Interactive Biotechnology Research Mission Timeline**: Smooth 12-event path route with real-time waypoint data and active status telemetry.
- 🎬 **Bio Bounty Video Scrubber**: 60 FPS GPU-accelerated video scrubbing showcasing the ₹3,500,000 prize pool.
- 🧬 **DNA Rope & Square Event Cards**: Interactive 3D swinging event cards with custom biotechnology microscope lens zoom cursor.
- 🏆 **Results & Gallery Portals**: Dynamic MongoDB Atlas event results display and symposium photo galleries.
- 🔑 **Authentication & Role-Based Dashboards**: Participant registration/login and Coordinator management dashboards.
- 💎 **Molecular Assembly Developer Credit**: 6-phase molecular assembly animation for developer **Janarthanan P**.
- 📱 **Universal Mobile Responsiveness**: 100% responsive layout optimized for mobile phones and tablets.

---

## 🛠️ Technology Stack
- **Backend**: Python (Flask Framework)
- **Database**: MongoDB Atlas (	echfinix26 database)
- **Frontend**: HTML5, CSS3, JavaScript (ES6+), GSAP (GreenSock Animation Platform)
- **Audio Engine**: Web Audio API Synthesizer (Mild Rain & Thunder)
- **Styling**: Space Grotesk, MedievalSharp, Cinzel Decorative typography with custom glassmorphism HUD styles.

## 🚀 Quick Start & Installation

### 1. Prerequisites
- Python 3.9+
- MongoDB Atlas Account / Connection String

### 2. Clone Repository
`ash
git clone https://github.com/jana12102005/TECHFINIX-WEBSITE.git
cd TECHFINIX-WEBSITE
`

### 3. Install Dependencies
`ash
pip install -r requirements.txt
`

### 4. Run Application
`ash
python app.py
`
The server will start at http://127.0.0.1:5000 (or http://0.0.0.0:5000).
